# TrustGuard - Forensic Verification Suite

An advanced, high-performance forensic verification platform engineered to analyze and verify media authenticity across images, videos, audio files, and network traffic logs.


### 🚀 Live Demo

Experience the application live: [TrustGuard PRO](https://trust-guard-pro.vercel.app)


### 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, HTML5, CSS3
- **Backend & Database:** Firebase Firestore
- **Deployment & Hosting:** Vercel Production Deployment


### 🔒 Security & Architecture

- **Authenticated Isolation:** Configured custom `firestore.rules` preventing unauthenticated data access loops.
- **Environment Management:** Secured sensitive backend mapping endpoints using local environment execution practices (`.env`).
- **Responsive Workspace:** Optimized user interfaces for forensic engineers handling multi-layered metadata viewing.
